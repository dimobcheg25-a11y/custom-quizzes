# Квізи від Дімона

Квіз для друзів онлайн у форматі «Своєї гри»: табло з темами й цінами, кнопка відповіді, кіт у мішку, аукціон, фінал зі ставками. Кожен гравець відкриває гру у своєму браузері (на ПК чи телефоні) і бачить усе: табло, питання, картинки, відео, музику, рахунок. Ведучий бачить правильні відповіді й оцінює гравців. Відповіді гравці кажуть голосом, наприклад у Discord.

## Запуск

Потрібен Node.js 22.

```
npm install
npm run build
npm start
```

Гра відкриється на http://localhost:3000.

### Як грати з друзями віддалено

Найпростіше — запустити гру у себе і відкрити її в інтернет через безкоштовний тунель Cloudflare (без реєстрації):

```
winget install --id Cloudflare.cloudflared -e
cloudflared tunnel --url http://localhost:3000
```

Cloudflare покаже адресу на кшталт `https://xxxx.trycloudflare.com` — надішліть її друзям. Паки беруться з папки `packs/` на вашому ПК.

Інший варіант — задеплоїти `Dockerfile` на будь-який хостинг із підтримкою WebSocket (Koyeb, Render, Fly.io). Паки з папки `packs/` потрапляють в образ; нові можна завантажити .zip-архівом на головній сторінці. Щоб сторонні не завантажували свої паки, задайте змінну `UPLOAD_KEY`.

## Як проходить гра

1. Ведучий на головній обирає пак і створює кімнату, надсилає гравцям посилання.
2. Гравці вводять ім'я й обирають колір. Коли всі зайшли, ведучий натискає «Почати гру».
3. Питання обирає гравець, який останнім відповів правильно (на початку — випадковий). Ведучий теж може обрати за нього.
4. Кнопка відкривається після читання питання (автоматично або ведучим). Натиснув раніше — фальстарт і коротке блокування. Хто натиснув швидше — відповідає. Пінг не дає переваги: враховується час реакції, виміряний у браузері гравця.
5. Ведучий тисне «Вірно» (1) чи «Невірно» (2). Неправильна відповідь знімає бали й відкриває кнопку для інших.
6. **Кіт у мішку** — гравець, який обирав, віддає питання іншому. **Аукціон** — гравці по черзі роблять ставки, переможець відповідає сам.
7. **Фінал** — грають лише ті, у кого рахунок більший за нуль: прибирають теми, роблять таємні ставки й пишуть відповідь.

Ведучий може змінити будь-чий рахунок, призначити, хто обирає, вигнати гравця й налаштувати таймери. Якщо гравець перезавантажить сторінку чи втратить зв'язок, він повернеться з тим самим рахунком.

## Паки

Пак — це папка `packs/<назва>/` з файлом `pack.json` і папкою `media/` з картинками, відео й музикою. Формат описано в `src/shared/pack.ts`.

Паки робить Claude Code: просто напишіть, наприклад, «зроби пак на 2 раунди про фільми 2000-х, меми та ігри, з картинками і вгадай мелодію». Для нарізки відео й музики з YouTube потрібні ffmpeg і yt-dlp:

```
winget install --id Gyan.FFmpeg -e
winget install --id yt-dlp.yt-dlp -e
```

Корисні команди:

- `npm run pack:check -- packs/<назва>` — перевірити пак;
- `npm run pack:zip -- packs/<назва>` — запакувати для завантаження на сайт;
- `npm run media:clip -- <youtube-url> 1:10 1:25 packs/<назва>/media/r1-t1-q1.mp4` — вирізати відеофрагмент (`.mp3` — лише звук, `.jpg` з `-` замість кінця — кадр);
- `npm run media:image -- <url> packs/<назва>/media/r1-t1-q2.jpg` — завантажити картинку.

## Розробка

- `npm run dev` — сервер і клієнт з гарячим перезавантаженням (http://localhost:5173).
- `npm test` — тести логіки гри, `npm run test:e2e` — повна гра в браузерах (ведучий + 3 гравці).
